## 测试流程

针对每个变体：

1. **先运行空白对照组**（无 Skills 文档）
   - 记录 Agent 选择了哪个选项
   - 记录其确切的合理化理由

2. **使用相同场景运行变体**
   - Agent 是否检查了 Skills？
   - 如找到 Skill，是否实际使用？
   - 如有违规，记录其理由

3. **压力测试** - 增加时间/沉没成本/权威压力
   - 在压力下 Agent 是否仍会检查？
   - 记录合规性在何时被突破

4. **元测试** - 询问 Agent 如何改进文档
   - “你当时有文档但没有检查，为什么？”
   - “文档怎样写才能更清晰？”

## 成功标准

**变体视为成功，当满足：**
- Agent 无需提示即主动检查 Skills
- Agent 在执行前完整阅读 Skill
- Agent 在压力下仍遵循 Skill 指引
- Agent 无法为违规行为找到合理借口

**变体视为失败，当出现：**
- 即使在无压力情况下也跳过检查
- 未阅读原文就“按概念自行发挥”
- 在压力下为跳过行为找借口
- 将 Skill 视为参考资料而非必须遵循的要求

## 预期结果

**空白对照组：** Agent 选择最快路径，无 Skill 意识

**变体 A：** 无压力时可能检查，压力下会跳过

**变体 B：** 有时会检查，但容易被合理化理由绕过

**变体 C：** 合规性强，但可能显得过于僵化

**变体 D：** 较为均衡，但篇幅较长——Agent 能否真正内化？
